A simplified but faithful model of Secure Boot v2 on the ESP32-C5 (ECDSA-P256 scheme). The ROM is trusted by construction; every later stage must present a signature that matches a public-key digest burned into eFuse. A single failed check aborts the boot — there is no recovery path to unsigned code. Full detail, including OTA slot fallback and the RSA/ECDSA options, is in SECURE_BOOT_DEEP_DIVE.md §1.
